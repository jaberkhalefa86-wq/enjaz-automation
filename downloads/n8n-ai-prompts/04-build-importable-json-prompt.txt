قالب 4 — إنشاء JSON متوافق مع إصدار n8n

أرفقت لك ملف JSON مرجعيًا تم استيراده ثم تصديره مباشرة من إصدار n8n الذي أستخدمه.

الغرض من الملف المرجعي هو معرفة البنية التقنية الصحيحة للعُقد في نسختي فقط.

مهم جدًا:
- الملف المرجعي ليس Workflow نهائيًا.
- لا تعتمد ترتيب العُقد الموجودة فيه كمعمارية.
- لا تنسخ IDs الخاصة بالعُقد المرجعية.
- استخدمه فقط لمعرفة type وtypeVersion وبنية parameters وصيغة onError وبنية ملف JSON المتوافقة مع نسختي.

اعتمد الآن:
1. المتطلبات النهائية التي وافقنا عليها.
2. المعمارية المعتمدة.
3. مواصفات كل Node التي راجعناها على مراحل.
4. ملف n8n المرجعي المرفق.

المطلوب:
أنشئ Workflow جديدًا كاملًا بصيغة JSON وقابلًا للاستيراد مباشرة في n8n.

قواعد إلزامية:
- استخدم العُقد الرسمية فقط ما لم تكن المعمارية المعتمدة تنص على غير ذلك.
- لا تضع API Keys أو Tokens أو Passwords أو Credentials داخل الملف.
- لا تنسخ IDs من الملف المرجعي؛ أنشئ IDs جديدة وفريدة.
- اجعل أسماء العُقد فريدة وواضحة.
- استخدم type وtypeVersion المتوافقين مع الملف المرجعي.
- حافظ على جميع الاتصالات Connections كما اعتمدناها.
- اضبط مخارج loop وdone للحلقات بطريقة صحيحة.
- إذا كانت Code Node تغيّر عدد العناصر أو تعيد بناءها، حافظ على pairedItem عند الحاجة.
- لا تستخدم Expressions تشير إلى Node غير موجودة.
- لا تستخدم قيمًا وهمية حساسة؛ استخدم placeholders واضحة للإعدادات التي سيضعها المستخدم بعد الاستيراد.
- اجعل active = false حتى يتم الاختبار قبل التفعيل.
- طبّق Timezone وإعدادات الـWorkflow التي اعتمدناها.

قبل الإخراج راجع داخليًا:
1. أن JSON صالح نحويًا.
2. وجود nodes وconnections.
3. جميع أسماء العُقد فريدة.
4. جميع IDs فريدة.
5. جميع العُقد المشار إليها في connections موجودة.
6. لا توجد عُقد يتيمة دون سبب مقصود.
7. مخارج الحلقات والعودة إليها صحيحة.
8. التقرير أو الخطوة النهائية تعمل فقط بعد انتهاء المعالجة إذا كان ذلك جزءًا من التصميم.
9. جميع Expressions تشير إلى أسماء عُقد موجودة.
10. جميع Code Nodes تعيد Items بصيغة n8n الصحيحة.
11. لا توجد Credentials أو أسرار.

المخرجات المطلوبة:
- أرسل ملف Workflow JSON كاملًا فقط داخل Code Block واحد من نوع json.
- لا تقسّم الملف إلى أجزاء.
- لا تختصر الأكواد.
- لا تكتب عبارات مثل: "أكمل الباقي بنفس الطريقة".
