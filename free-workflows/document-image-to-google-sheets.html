ورك فلو مجاني 🎁

استخرج بيانات صورة المستند إلى Google Sheets تلقائيًا

أرسل صورة المستند إلى بوت Telegram، وسيقرأها ورك فلو n8n، ويستخرج الحقول المحددة ثم يضيفها في صف جديد داخل Google Sheets.

تحميل الملفات مجانًا قراءة خطوات التشغيل
📷إرسال الصورةعبر بوت Telegram
🔄تحويل الملفإلى Base64
🤖قراءة الحقولباستخدام Groq
📊حفظ البياناتداخل Google Sheets

محتويات ملف التحميل

  • ملف ورك فلو n8n بصيغة JSON.
  • قالب CSV جاهز بأسماء أعمدة Google Sheets.
  • ملف تعليمات عربي خطوة بخطوة.

الحقول المستخرجة حاليًا

  • CRM Order Id
  • Customer Name
  • Contact Phone
  • Internet Service No.

خطوات التشغيل بعد التحميل

  1. فك ضغط الملف، ثم استورد ملف JSON إلى n8n.
  2. اربط عقدة Telegram Trigger بالبوت الخاص بك.
  3. ضع مفتاح Groq في عقدة HTTP Request بدل YOUR_GROQ_API_KEY.
  4. استورد قالب CSV إلى Google Sheets أو أنشئ الأعمدة الأربعة يدويًا.
  5. اربط عقدة Google Sheets بحسابك واختر الجدول والورقة.
  6. اختبر الورك فلو بإرسال صورة واضحة إلى البوت، ثم فعّله.
الملف لا يحتوي على مفاتيح API أو بيانات دخول خاصة. ستحتاج إلى إضافة حساباتك ومفتاح Groq بعد الاستيراد.
